# Relatório de Implementação - Testes de Rotação Real

**Data:** 03-02-2026  
**Tarefa:** Implementar testes reais enviando 1 prompt a cada 1 minuto para modelos diferentes.

## O que foi feito
- Criado o script `scripts/real_rotation_test.ts`.
- Implementada lógica de rotação que percorre o arquivo `free_models.json`.
- Configurado um intervalo de 60 segundos (1 minuto) entre cada requisição para respeitar limites de taxa e simular uso real estável.
- Adicionado sistema de logging que escreve tanto no console quanto no arquivo `rotation_results.log`.
- Adicionado o atalho `npm run test:real-rotation` (via bun) no `package.json`.

## Por que foi feito
A pedido do usuário para validar a estabilidade da biblioteca `one-llm-4-all` em um cenário de integração real com diversos modelos do OpenRouter free tier. O intervalo de 1 minuto garante que não seremos bloqueados por rate limits agressivos e permite observar o comportamento de diferentes modelos sequencialmente.

## Como funciona
1. O script carrega a lista de modelos de `free_models.json`.
2. Filtra o modelo genérico `openrouter/free`.
3. Para cada modelo restante, envia um prompt e aguarda a resposta.
4. Loga o tempo de resposta, o sucesso/erro e um preview da resposta.
5. Aguarda exatamente 60.000ms antes de prosseguir para o próximo modelo.

## Como testar
Para iniciar o teste real, execute no WSL:
```bash
bun run test:real-rotation
```
Ou com um prompt customizado:
```bash
bun run scripts/real_rotation_test.ts "Seu prompt aqui"
```
Os resultados podem ser acompanhados em tempo real no arquivo `rotation_results.log`.
